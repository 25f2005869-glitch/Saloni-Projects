# 🔐 Python Password Generator

A beginner-friendly Python project that generates secure and random passwords using letters, numbers, and special characters.

This project demonstrates the use of Python's built-in modules for randomization and string manipulation while creating strong passwords for improved security.

---

## 📖 Project Overview

Passwords are an essential part of digital security. This project allows users to generate random passwords of custom length using:

- Uppercase Letters (A-Z)
- Lowercase Letters (a-z)
- Numbers (0-9)
- Special Characters (!@#$%^&*)

The generated password is randomized to improve strength and unpredictability.

## ⚙️ How It Works

1. User enters desired password length.
2. Program creates a pool of:
   - Letters
   - Numbers
   - Symbols
3. Random characters are selected.
4. Password is generated and displayed.
