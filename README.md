# Saloni Projects

This repository contains a collection of useful and educational projects, mainly focusing on Python, Data Analysis, and GUI development. These projects serve as excellent practice material and references for beginner and intermediate coders.

## Projects Included

Below is the list of available projects in this repository, along with a short description for each:

1. **Library-Management-System-cli-gui-pro**
   - A library management system featuring both CLI and GUI interfaces.
2. **Student-Management-System-gui**
   - A GUI application for managing student data.
3. **excel-sales-dashboard-project**
   - A sales visualization dashboard built using Excel.
4. **matrix_calculator_advanced_gui**
   - An advanced matrix calculator with a graphical interface.
5. **pharmacy-billing-system-cli-gui**
   - CLI and GUI based billing system for pharmacy stores.
6. **python-calculator-project-cli-gui-pro**
   - An advanced calculator project in Python with both CLI and GUI.
7. **python-password-generator**
   - A Python script for generating secure passwords.
8. **python-todo-cli-gui-pro**
   - Python-based to-do list application with both CLI and GUI for organizing daily tasks.
9. **sales_data_analysis_project**
   - A project for analyzing sales data (Python/Excel based).
10. **student-performance-dashboard**
    - A dashboard for visualizing student performance using data analysis techniques.

## Usage

- Each project has its own folder within this repository.
- Please refer to the instructions or comments within each project’s folder before running the code.
- For Python projects, it’s recommended to set up a virtual environment and install any necessary dependencies (see `requirements.txt` if available).
